## Задание:

1. На всех компьютерах настроить IP DNS сервера
2. Настроить статический маршрут между роутерами R0 и R1
3. Создать и настроить VLAN 30 (имя Business)
4. Компьютеры из VLAN 10, должны общаться с компьютерами из VLAN 20, 30 => выбрать между Trunk и Native Trunk и настроить его между Switch2 и Router0
5. Протестировать всю сеть и выполнить troubleshooting если необходимо
6. Ответить на вопросы

7. В разница между Trunk и Native trunk?
Разница в том что Trunk сохраняент teg, а native trunk нет. 
8. Зачем нужны подинтерфейсы?
Они нужны для того, чтобы компьютеры из разных vlan могли общаться между собой. Это работает за счёт, что на роутере создаётся подинтерфейс (router-on-a-stick)

9. На каких двух устройствах как правило настраиваются подинтерфейсы?
На роутере и на комутаторахL3.

10. Опиши процесс попадания кадра из VLAN10 в VLAN 20
1) На подинтерфейс приходит кадр из VlAN10.
2) Роутер снял оболочку L2(кадр -> пакет).
3) Роутер достаёт ip adress.
4) Он смотрит на блок ip address destination.
5) По таблице маршрутизации роутер понимает, что ip из другого VLan.
6) Создает кадр для VLAN 20.
7) Отправляет кадр через интерфейс trunk.

## Решение
1) На каждом компьютере был настроен ip DNS 10.0.2.2
2) RO:
```
ip route 10.0.2.0 255.255.255.252 10.0.1.2
```
R1:
```
ip route 192.168.10.0 255.255.255.0 10.0.1.1
ip route 192.168.20.0 255.255.255.0 10.0.1.1
ip route 192.168.30.0 255.255.255.0 10.0.1.1
```
3) Настройка Vlan30:
```
vlan 30
name Bussiness
exit
int fa0/3
switchport mode access
switchport access vlan 30
```
4) R0:
```
int g0/0/0.10
encupsulation dot1Q 10
ip address 192.168.10.1 255.255.255.0
```
```
int g0/0/0.20
encupsulation dot1Q 20
ip address 192.168.20.1 255.255.255.0
```
```
int g0/0/0.30
encupsulation dot1Q 30
ip address 192.168.30.1 255.255.255.0
```
SW2:
```
int g0/0
switchport mode trunk
switchport trunk allowed 10,20,30
```
